# Темы для Uptime Kuma

Кастомные CSS-темы для публичной страницы статуса Uptime Kuma.
HTML не меняется — всё вешается на существующие классы приложения.

## Как поставить

Status Page → **Edit Status Page** → поле **Custom CSS** → вставить
содержимое файла целиком → **Save**.

## Темы

| Файл | Что это |
|---|---|
| `signal-dark.css` | Тёмная «операторская» тема: приглушённый неоново-зелёный акцент, волосяные линии, группа как секция с уходящей линейкой, состояние падения подсвечивается через `:has()`. |
| `console-crt-amber.css` | Янтарный CRT-терминал: моноширинный шрифт, скан-линии, квадратный пульс, обводочные кнопки. |

## На что опирается signal-dark

Разметку брали из реальной выгрузки страницы (`/status/pt`), стили — из
`index-bOVKKa1O.css` самого Uptime Kuma. Важные особенности базы, которые
пришлось учесть:

- `.shadow-box { padding: 10px }` — карточка группы имеет внутренний отступ,
  из-за него подсветка строки не доходила до краёв. Снимаем в `0`.
- `.extra-info { display: flex; margin-bottom: .5rem }` — пустой блок всё
  равно занимал место под каждой строкой. Прячем через `:empty`.
- `.badge { min-width: 62px }` — оставляем, за счёт этого проценты аптайма
  выстраиваются в столбик.
- `.bg-primary` у Bootstrap объявлен с `!important`, поэтому бейдж
  перекрываем составным селектором `.badge.bg-primary`.
- ширина и отступы `.beat` заданы инлайном и пересчитываются в JS —
  трогаем только высоту и цвет, иначе разъедется подпись «39m ago».

## Состояния без JavaScript

`signal-dark.css` определяет состояние монитора через `:has()`:

- последний удар пульса `.down` → строка краснеет, слева красная метка,
  рамка группы краснеет;
- падения были, но сейчас всё поднято → янтарная метка слева;
- баннер сверху красится по классу иконки (`.ok` / `.warning` / `.danger`).
